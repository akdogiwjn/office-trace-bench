# Historical synthetic development workloads

These Retail / Manufacturing / HR workbooks are NOT the formal suite.
Official source observations were transformed into deterministic synthetic shards,
100000 rows x 16 columns, with seven base sheets and two existing charts.
They are canonicalized benchmark-generated workbooks, not 100000 observed retail,
manufacturing, or employee records. Their builders and qualification scripts are
archived historical source, not supported active dataset-generation commands.
Current inputs and machine-verifiable bindings are in datasets/ and artifacts/suite.json.
