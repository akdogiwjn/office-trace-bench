# SBA 1919 native fillable benchmark

Frozen version: SBA Form 1919 04.2024.pdf, seven pages, 127 leaf fields.
Public SBA Box source: https://sba.app.box.com/s/iud0tv5euaw4cdvv3itmbrc2tp2p7etf
Original downloaded PDF bytes are preserved.
The current 2025 official PDF download returned 403. A downloaded 2025 bank mirror has no AcroForm; neither is used here.
This is a version-pinned training benchmark, not a current loan application. Ten fictional businesses are supplied.
Read input/dataset_manifest.json for exact semantic field rules and checkbox export states.
Copy only supplied business, owner, workforce, working-capital and yes/no answers.
Keep every other field blank, including all business/owner TINs, Unique Entity ID, optional demographics,
initials, signatures, dates and the certification print-name/title fields. Do not add overlays, certifications or identifiers.
